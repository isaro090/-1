# Безопасность

## Границы доступа

- Coding-agent работает с относительными путями внутри выбранной папки; абсолютные пути, выход через `..` и обнаруженные ссылки за пределы папки отклоняются.
- При замене файла приложение сохраняет предыдущую копию. Инструмент удаления делает восстанавливаемую копию в локальной корзине KeyAI; каталог целиком не удаляется.
- Одна операция читает текстовый файл до 500 КБ, создаёт/меняет файл до 1 МБ. Обход ограничен глубиной 7 и 1200 файлами; стандартные тяжёлые каталоги исключены.
- Терминал запускает PowerShell только после отдельного системного подтверждения. Время процесса ограничено 30 секундами, вывод — 1 МБ.
- Встроенный браузер принимает только HTTP(S); удалённые страницы не получают командный API приложения. Интеграция Servo/Verso экспериментальная.

## Секреты и содержимое запросов

API-ключи хранятся через Windows Credential Manager. Не добавляйте ключи в Git, переменные workflow, скриншоты или публичные issue. Сообщения, выбранные файлы и результаты вызовов инструментов отправляются API-провайдеру, выбранному пользователем; провайдер задаёт свои правила обработки и хранения.

Встроенный браузер открывает внешние сайты, которые могут собирать обычные данные браузера. Не вводите на незнакомых сайтах секреты, если не доверяете им.

## Сообщить об уязвимости

Не публикуйте действующие ключи, токены, приватные файлы или эксплойты в issue. Для приватного сообщения используйте GitHub Security Advisories, если они включены для репозитория, либо контакт владельца репозитория.
