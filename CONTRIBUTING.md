# Вклад в KeyAI 1

1. Создайте ветку для изменения и опишите проблему или сценарий использования.
2. Не включайте API-ключи, пользовательские чаты, логи, рабочие каталоги и содержимое секретных файлов.
3. Поддерживайте границы доступа к выбранной рабочей папке; не добавляйте обход подтверждения для shell-команд.
4. Перед PR запустите `cargo fmt --check`, `cargo check --manifest-path src-tauri/Cargo.toml` и сборку Windows через workflow **Build Windows**.
5. Для изменений интерфейса приложите снимки реально запущенной Servo-сборки. Не обозначайте Chromium/WebView2-макет как снимок Servo.

Для API-ключей, подписок и доступа к сторонним моделям используйте собственные аккаунты и правила провайдера.
