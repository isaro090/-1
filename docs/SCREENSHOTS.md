# Визуальный материал

`screenshots/ui-preview.svg` — подготовленный SVG-макет интерфейса проекта. Он показывает ожидаемую компоновку: Mac-подобная верхняя панель, тёмный фон, зелёное сообщение пользователя, выбор API-модели и интенсивности, coding-панель и встроенный браузер.

Снимок экрана работающего EXE пока не включён: локально нет Rust/MSVC для сборки, а прежняя Electron-версия использует Chromium и не является снимком Servo/Verso. Добавьте реальные снимки после успешной сборки и проверки через GitHub Actions.
